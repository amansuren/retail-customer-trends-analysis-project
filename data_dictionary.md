
## Data Dictionary

### [Customer Shopping Behaviour Dataset](dataset/customer_shopping_behaviour_cleaned.csv)

### Dataset Overview

This dataset contains customer demographic information, purchasing behaviour, transaction details, product preferences, and engagement metrics. It is designed to support customer behavior analysis, segmentation, retention studies, and business intelligence reporting.
## Column Definitions

| Column Name | Data Type | Description |
|------------|------------|-------------|
| customer_id | VARCHAR | Unique identifier for each customer |
| age | INTEGER | Age of the customer |
| gender | VARCHAR | Customer gender |
| item_purchased | VARCHAR | Product purchased by customer |
| category | VARCHAR | Product category |
| purchase_amount | DECIMAL | Amount spent during transaction |
| location | VARCHAR | Customer geographic location |
| size | VARCHAR | Product size selected |
| color | VARCHAR | Product color selected |
| season | VARCHAR | Season in which purchase occurred |
| review_rating | DECIMAL | Customer satisfaction rating (1-5) |
| subscription_status | VARCHAR | Indicates membership/subscription status |
| shipping_type | VARCHAR | Selected shipping method |
| discount_applied | VARCHAR | Indicates whether discount was applied |
| previous_purchases | INTEGER | Number of previous purchases made by customer |
| payment_method | VARCHAR | Payment method used for purchase |
| frequency_of_purchases | VARCHAR | Purchase frequency category |
| age_group | VARCHAR | Categorized age segment |
| purchase_frequency_days | INTEGER | Average days between purchases |
